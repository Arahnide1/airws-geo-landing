# GEO-лендинг AiR

Статичный лендинг: HTML + CSS + JS. Формы отправляются через `send.php` в Битрикс24.

## Файлы
- `index.html` — страница
- `assets/css/style.css` — стили (токены сняты с airws.ru)
- `assets/js/main.js` — демо-чат, анимации, цели Метрики, UTM, отправка форм
- `send.php` — обработчик форм → Битрикс24 `crm.lead.add`
- `config.example.php` — шаблон настроек. Скопировать в `config.php` и заполнить

## Запуск на хостинге
1. Залить папку на хостинг с PHP 7.4+ и расширением curl, например на поддомен `geo.airws.ru`.
2. Создать в Битрикс24 (corp-airws.ru) входящий вебхук: «Разработчикам» → «Другое» → «Входящий вебхук», права **CRM**.
3. `cp config.example.php config.php` и вставить URL вебхука в `b24_webhook`.
4. Отправить тестовую заявку и проверить, что лид появился в CRM с UTM-метками.

Что попадает в лид: название с типом формы, имя, телефон, сайт, тариф, способ связи, UTM (source/medium/campaign/content/term), yclid, ClientID Метрики, страница и реферер.
Если Битрикс24 не ответил, заявка уходит письмом на `fallback_email`.

## Яндекс.Метрика
Счётчик **16999798**, тот же, что на airws.ru. Чтобы считать лендинг отдельно, заменить ID в `index.html` (2 места) и в `main.js` (`YM_ID`).

Цели, которые нужно создать в Метрике (тип «JavaScript-событие»):

| Идентификатор | Когда срабатывает |
|---|---|
| `lead` | Любая успешная заявка (**основная цель для Директа**) |
| `lead_audit` | Заявка на бесплатный AI-срез |
| `lead_lead` | Заявка из финальной формы |
| `lead_error` | Ошибка отправки |
| `form_start_audit`, `form_start_lead` | Начал заполнять форму |
| `cta_hero`, `cta_header`, `cta_mobile_bar`, `cta_hero_prices` | Клики по CTA |
| `tariff_start`, `tariff_growth`, `tariff_leader` | Выбор тарифа |
| `phone_click`, `email_click`, `tg_click`, `max_click` | Контакты |
| `demo_tab` | Переключение нейросети в демо |
| `faq_open` | Открыт вопрос FAQ |
| `scroll_50`, `scroll_90` | Глубина скролла |

## Перед запуском рекламы
- Заменить демонстрационные кейсы на реальные или согласовать формулировки.
- Согласовать тарифы «Рост» (35 000 ₽) и «Лидер» (65 000 ₽) и их состав.
- Проверить обещание «AI-срез за 1 рабочий день».

## GitHub Pages
Версия на `*.github.io` нужна для показа и согласования. PHP там не выполняется, поэтому формы работают в демо-режиме: показывают «Заявка принята», но ничего не отправляют. Для рекламы лендинг нужно залить на хостинг с PHP.

## Локальный просмотр
`python -m http.server 8765 --directory landing`. На localhost формы не отправляются в Битрикс: данные выводятся в консоль браузера.
