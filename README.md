# Лендинги AiR

Статичные лендинги на общей дизайн-системе: HTML + CSS + JS. Формы отправляются через общий `send.php` в Битрикс24.

| Лендинг | Путь | Префикс целей Метрики |
|---|---|---|
| GEO-продвижение | `/` (`index.html`) | нет |
| Контекстная реклама | `/context/` | `ctx_` |

## Файлы
- `index.html` — GEO-лендинг
- `context/index.html` — лендинг контекстной рекламы (демо выдачи задаётся в `window.AIR_DEMO` внизу страницы)
- `assets/css/style.css` — общие стили (токены сняты с airws.ru) и блоки обоих лендингов
- `assets/js/main.js` — демо, анимации, калькулятор, цели Метрики, UTM, отправка форм. Настройки страницы берутся из атрибутов `<body>`: `data-landing`, `data-goal-prefix`, `data-endpoint`
- `send.php` — обработчик форм → Битрикс24 `crm.lead.add`. Название лида начинается с «GEO-лендинг» или «Контекст-лендинг»
- `config.example.php` — шаблон настроек. Скопировать в `config.php` и заполнить

## Запуск на хостинге
1. Залить папку целиком на хостинг с PHP 7.4+ и расширением curl, например на поддомен `promo.airws.ru` (тогда GEO будет в корне, контекст на `/context/`).
2. Создать в Битрикс24 (corp-airws.ru) входящий вебхук: «Разработчикам» → «Другое» → «Входящий вебхук», права **CRM**.
3. `cp config.example.php config.php` и вставить URL вебхука в `b24_webhook`.
4. Отправить тестовую заявку с каждого лендинга и проверить, что лид появился в CRM с UTM-метками.

Что попадает в лид: лендинг и тип формы, имя, телефон, сайт, тариф, способ связи, есть ли реклама сейчас и бюджет из калькулятора (контекст), UTM (source/medium/campaign/content/term), yclid, ClientID Метрики, страница и реферер.
Если Битрикс24 не ответил, заявка уходит письмом на `fallback_email`.

## Яндекс.Метрика
Счётчик **16999798**, тот же, что на airws.ru. Чтобы считать лендинги отдельно, заменить ID в `<head>` каждой страницы и в `main.js` (`YM_ID`).

Цели (тип «JavaScript-событие»). Для лендинга контекста те же цели создаются с префиксом `ctx_`: `ctx_lead`, `ctx_lead_audit` и т. д.

| Идентификатор | Когда срабатывает |
|---|---|
| `lead` | Любая успешная заявка (**основная цель для Директа**) |
| `lead_audit` | Заявка из формы лид-магнита (AI-срез / аудит рекламы) |
| `lead_lead` | Заявка из финальной формы |
| `lead_error` | Ошибка отправки |
| `form_start_audit`, `form_start_lead` | Начал заполнять форму |
| `cta_hero`, `cta_header`, `cta_mobile_bar`, `cta_hero_prices`, `cta_hero_calc` | Клики по CTA |
| `tariff_*` | Выбор тарифа (GEO: `start`, `growth`, `leader`; контекст: `audit`, `base`, `optimal`) |
| `calc_use`, `calc_cta` | Калькулятор бюджета (контекст) |
| `case_open` | Переход в полный кейс (контекст) |
| `phone_click`, `email_click`, `tg_click`, `max_click` | Контакты |
| `demo_tab` | Переключение вкладки в демо |
| `faq_open` | Открыт вопрос FAQ |
| `scroll_50`, `scroll_90` | Глубина скролла |

## Перед запуском рекламы
**GEO**
- Заменить демонстрационные кейсы на реальные или согласовать формулировки.
- Согласовать тарифы «Рост» (35 000 ₽) и «Лидер» (65 000 ₽) и их состав.
- Проверить обещание «AI-срез за 1 рабочий день».

**Контекст**
- Кейсы и тарифы взяты со страницы airws.ru/services/reklama/context/. На ней указано и «от 18 000 ₽», и пакеты за 15 000 / 25 000 ₽. На лендинге стоят цены пакетов, нужно сверить.
- Кейс Yans со страницы контекста не использован: по ссылке кейс разработки сайта без рекламных цифр.
- У «Нового Дома» на странице airws одновременно «+17% заявок» и «в 3 раза». На лендинге взято +17%.

## Обновление стилей и скриптов
GitHub Pages кеширует файлы до 10 минут. После правок в `style.css` или `main.js` увеличьте версию `?v=` в подключении на обеих страницах.

## GitHub Pages
Версия на `*.github.io` нужна для показа и согласования. PHP там не выполняется, поэтому формы работают в демо-режиме: показывают «Заявка принята», но ничего не отправляют. Метрика на github.io и localhost не подключается. Для рекламы лендинги нужно залить на хостинг с PHP.

## Локальный просмотр
`python -m http.server 8765 --directory landing`. На localhost формы не отправляются в Битрикс: данные выводятся в консоль браузера.
